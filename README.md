## 四个前排测评没讲清的限制

**1. 流量超了，不同机房处理方式不一样**

香港、新加坡、日本、台湾、荷兰这几个机房是限速不停机：高速流量用完，带宽降到 5Mbps 继续跑，不额外收费，也不会断服务。洛杉矶和澳洲的套餐是限制高速流量，没有这层"降速续命"的缓冲。

对直播来说这个差别很实际。5Mbps 大概够 720p 推流，跑不了了但也不至于直接掉线；而限制高速流量的套餐超了就真没速度了。买之前想清楚自己一个月大概跑多少。

**2. 流量按双向算**

上传加下载合计。标称 1TB，实际可用场景更接近单向 500GB。刷视频、传素材这种上下行都吃流量的用法，消耗比想象中快。

**3. 澳洲机房对电信用户不友好**

移动和联通走澳洲是直连，延迟 80–120ms；电信用户会绕美国，延迟明显更高。人在国内、主力宽带是电信，就别为了"澳洲原生 IP"硬选悉尼。

**4. 部分欧洲、东南亚节点需要额外买中转**

官方自己提供收费中转服务。这类节点国内直连速度不理想，买之前先确认你的用途能不能接受这个额外成本，别只看月付价格便宜。

## 常见问题

**韩国两款差 28 块，贵的那个更好吗？**

不一定。世宗（¥118.46）是双 ISP 住宅 IP，电信和移动直连，联通部分绕路；¥89.91 那款是原生韩国家宽，官方宣称三网直连。你用联通，便宜的那款路由更顺；你用电信或移动、又更看重住宅 IP 属性，才值得多花这 28 块。

**洛杉矶 Pro 和 AS9929 有什么区别？**

Pro 是去程走国内骨干网，回程走 CMIN2 / AS9929 / CN2；AS9929 是回程固定 AS9929，且全部配双 ISP IP。两条产品线的套餐在第三方页面都没标全价格，配置档位也不一样，实际价格去结算页看。

**能解锁 Netflix、TikTok 吗？**

第三方测评的说法是原生 IP 和双 ISP 住宅 IP 在这两个平台表现都不错，被封概率比机房 IP 低。这是测评结论，不是官方承诺。IP 被墙属于条款里的不退款情形，先月付测。

**流量超了会断网吗？**

香港、新加坡、日本、台湾、荷兰限速到 5Mbps 继续用；洛杉矶和澳洲是限制高速流量。都不会自动扣费。

**支持人民币付款吗？**

支持人民币和澳元双币种计费，支付宝、PayPal、信用卡都能用。实际扣款按结算页汇率换算，别拿第三方文章的汇率数字去算。
